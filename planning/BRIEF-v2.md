# Brief v2 (2026-11-01): learn Wittgenstein by playing

Owner's words: 不是以维特根斯坦的方式来学英语，而是用英语来学习维特根斯坦的哲学。
"Not learning English the Wittgenstein way, but learning Wittgenstein's philosophy, in English."

- **Subject:** Wittgenstein's philosophy, early to late. Each game makes one idea something you *do*,
  then names the idea, quotes the passage and says where the game's analogy stops.
- **Language:** English throughout. English skills are not a learning goal, scored item or selling point.
- **Audience:** curious adults and students meeting Wittgenstein for the first time; no philosophy background.
- **Path:** Tractatus (pictures of facts, the limits of language, the ladder) → language-games (§§1–27) →
  meaning as use (§43) → family resemblance (§§65–77) → following a rule (§§185–242) →
  private language (§§243–315, the beetle in the box) → certainty and hinges (On Certainty).
- **Interface:** designed with Codex's gpt-image-2 (mock-ups first, then implementation that matches them),
  on every page, not only the landing page. Legibility first.
- **Process:** Claude builds; Codex reviews the running site and the philosophy; repeat until Codex says it is satisfied.
- Kept from v1: Next.js, no login, progress in the browser, phone and desktop, sources with limits, no dark patterns.
